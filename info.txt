Diseñé y desarrollé de forma integral un sistema web de almacén orientado a procesos de manufactura, utilizando ASP.NET Core, C#, React, TypeScript y MySQL. El sistema fue creado para administrar inventario, solicitudes de materiales y operaciones de surtido en tiempo real.

Implementé un módulo de gestión de solicitudes de materiales con flujo completo de operación, incluyendo los estados Pendiente, Asignada, En surtido, Parcial, Completada y Entregada. Desarrollé la lógica de surtido parcial con descuento automático de inventario y actualización de existencias en tiempo real.

Diseñé y construí la base de datos relacional en MySQL, así como los servicios backend mediante API REST seguras con autenticación y autorización basada en JWT. Implementé control de sesiones y mecanismos de seguridad para el acceso al sistema.

Desarrollé módulos para control de inventario, consulta de existencias, trazabilidad de movimientos mediante Kardex y monitoreo operativo a través de dashboards en tiempo real. También integré funcionalidades de escaneo de códigos de barras para agilizar las operaciones de almacén.

Implementé procesos de importación masiva de información de producción mediante archivos BOM y 5MF, permitiendo la administración automática de materiales, arneses, diseños y planeación operativa. Adicionalmente desarrollé alertas automáticas para la detección de cambios de diseño y seguimiento de materiales relacionados con producción.

Configuré ambientes de desarrollo y producción, aplicando prácticas de despliegue, publicación de aplicaciones, manejo de variables de entorno y preparación para hospedaje en IIS, permitiendo la puesta en marcha del sistema dentro de la red interna de la empresa.
